# Примеры использования

Эти примеры дополняют основной сценарий из [README проекта](../README.md). Выбирайте нужный; для обычного запуска лаборатории выполнять их все не требуется.

| Каталог | Для чего нужен | С чего начать |
|---|---|---|
| `backup/` | Подключить роль `pbm` к уже работающему replica set и существующему S3 без установки MongoDB и хранилища | [Инструкция интеграции](../docs/integration.md); inventory и playbook находятся в этом каталоге |
| `monitoring/` | Подключить метрики, правила ошибок, дашборд Grafana и Telegram к своему мониторингу | [Инструкция мониторинга](monitoring/README.md) |
| `scheduler/` | Запускать проверочное восстановление по расписанию на готовом Ansible-контроллере | [Пример systemd-таймера](scheduler/README.md) |
| `scaling/` | Повторить сравнение копирования и восстановления баз объёмом 1–5 ГиБ на отдельных тестовых экземплярах | [Инструкция эксперимента](scaling/README.md) |

Примеры не разворачивают управляющую ВМ, сеть, Prometheus или Grafana. Адреса и параметры доступа в шаблонах нужно заменить своими. Локальные `backup/hosts.yml`, `backup/secrets.yml` и отчёты в `artifacts/` исключены из Git.
