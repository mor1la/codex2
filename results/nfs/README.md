# Исходный эксперимент с NFS

Исторический прогон до перехода на S3.

Прогон 16 ноября 2026 на трёх ВМ. База `dr_trial` содержала 262 144 документа и 1,014 ГиБ BSON до нагрузки. Генератор выполнил два окна по 750 операций, 50 операций/с.

| Этап | Вставки / обновления / удаления | BSON записей oplog | Новые файлы в архиве | Время |
|---|---:|---:|---:|---|
| Базовый снимок | — | — | 1,014 ГиБ | 18,18 с |
| PITR 1 | 173 / 459 / 118 | 2,71 МиБ | 2,55 МиБ | 15,57 с нагрузка, 65,80 с ожидание PBM |
| PITR 2 | 211 / 431 / 108 | 2,75 МиБ | 2,58 МиБ | 15,52 с нагрузка, 35,51 с ожидание PBM |

Между снимками в архив добавилось два сегмента общим размером 5,13 МиБ, около 0,49% размера базового снимка. Ожидание PBM отражает минутный цикл нарезки, а не только время передачи файлов. [Манифест эксперимента](experiment.json)

С отключёнными MongoDB и PBM на источнике восстановлена `dr_trial` на **20:27:45 UTC**. В DR совпали SHA-256, размер BSON, 262 302 документа и список индексов. MongoDB вернула `valid: true`, контрольная запись после целевого времени отсутствовала.

| Этап восстановления | Измеренное время |
|---|---:|
| Синхронизация уже заполненного локального staging | 0,10 с |
| Импорт каталога PBM | 0,34 с |
| Восстановление снимка и воспроизведение oplog | 34,07 с |
| Полная проверка MongoDB и сравнение данных | 10,80 с |

Время копирования в пустой staging и переключения приложения в эту таблицу не входит. Точка эксперимента была намеренно выбрана раньше контрольной записи. Её возраст на момент остановки источника не является оценкой RPO. [Отчёт восстановления](recovery.json)

`artifacts/` содержит локальные результаты новых запусков.
