# Практический прогон S3

17 ноября 2026 по Москве. Источник .248, бакет Versity на .247, восстановление на .249. Код и конфигурация стенда соответствуют параметрам в [манифесте эксперимента](experiment.json).

| Этап | Новые объекты в S3 | Вставки / обновления / удаления | Замер |
|---|---:|---:|---|
| Логический снимок | 2,029 ГиБ | — | 35,13 с |
| Первое окно oplog | 2,55 МиБ | 173 / 459 / 118 | 15,80 с нагрузки, 70,89 с ожидания PBM |
| Второе окно oplog | 2,58 МиБ | 211 / 431 / 108 | 15,48 с нагрузки, 35,65 с ожидания PBM |

Новая коллекция заняла 1,014 ГиБ BSON. Полный снимок включал и базу предыдущего NFS-эксперимента, поэтому сравнивать время полных снимков между этими прогонами напрямую нельзя. Два окна дали 5,13 МиБ объектов oplog, около 0,25% общего размера снимка. Сегмент с контрольной записью за границей PITR записан дополнительно. Ожидание включает интервал нарезки PBM.

Источник был остановлен, старые NFS-монтирования были отключены. PBM восстановил базу из S3 до **21:04:50 UTC**. В восстановленной коллекции 262 302 документа. Размер BSON, SHA-256 и индексы совпали, `validate` завершился успешно, контрольная запись отсутствовала.
